## Что умеет

**Фон.** Картинка, GIF или видео (mp4, webm) вместо стандартного чёрного. Можно собрать галерею,
включить слайдшоу или отдельные фоны на день и ночь. Размытие, затемнение и прозрачность панелей
настраиваются ползунками.

**Цвет.** Свой акцентный цвет или автоматически из обложки текущего трека. Кнопка воспроизведения,
прогресс-бар, свечение и визуализатор плавно перекрашиваются под каждую песню.

**Эффекты.** Визуализатор спектра над плеером (полосы, волна, зеркало), обложка и свечение
пульсируют под бас. Для слабых ПК есть режим «меньше анимаций».

**Моя волна без лишнего.** Убирает портреты артистов, переливающуюся анимацию и кислотный градиент,
оставляя страницу поверх вашего фона.

<p align="center">
  <img src="assets/screenshots/mini-player.png" width="420" alt="Мини-плеер">
</p>

**Мини-плеер.** Компактное окно поверх всех окон: обложка, перемотка, лайк. Не перехватывает фокус
у игры и прячется само, когда запущено что-то полноэкранное. `Ctrl+Alt+M` скрывает и показывает его
откуда угодно, `Ctrl+Alt+G` делает полупрозрачным, чтобы клики проходили сквозь.

**Discord.** Статус «Слушает» с обложкой, исполнителем, полосой времени и кнопкой на трек.

**И ещё:** пресеты с экспортом в JSON, громкость колёсиком мыши, горячие клавиши.

## Установка

1. Нужна [Яндекс Музыка для Windows](https://music.yandex.ru/download/).
2. Скачайте `YMusicMod-Setup.exe` со страницы [релизов](https://github.com/attent10nc/YMusicMod/releases/latest) и запустите.
3. Установка начнётся сама, Яндекс Музыка перезапустится. Настройки открываются по `Ctrl+Shift+Y`
   или через язычок у левого края окна.

Если программа стоит не в стандартной папке, установщик попросит её указать.

Windows может показать предупреждение SmartScreen, потому что файл не подписан сертификатом:
«Подробнее» → «Выполнить в любом случае».

### После обновлений Яндекс Музыки

При включённой опции «Возвращать мод после обновлений» в автозагрузку добавляется маленький
процесс (около 10 МБ памяти). Он замечает, что приложение обновилось, и через несколько секунд
возвращает мод. Мод не привязан к конкретной версии Яндекс Музыки: он встраивается в начало и конец
файлов приложения, а не в его внутренний код.

### Удаление

Запустите установщик и нажмите «Удалить». Оригинальные файлы приложения восстанавливаются из
резервной копии. Ваши настройки и фоны остаются в `%APPDATA%\YandexMusic\YMusicMod`.

## Горячие клавиши

| | |
|---|---|
| `Ctrl+Shift+Y` | панель настроек |
| `Ctrl+Shift+B` | пульс под бит |
| `Ctrl+Shift+V` | режим визуализатора |
| `Ctrl+Shift+P` | следующий пресет |
| `Ctrl+Shift+N` | следующий фон |
| `Ctrl+Shift+M` | мини-плеер |
| `Ctrl+Shift+R` | меньше анимаций |
| `Ctrl+Alt+M` | скрыть / показать мини-плеер, работает и в играх |
| `Ctrl+Alt+G` | мини-плеер «призрак» |

## Вопросы

<details>
<summary>Это безопасно для аккаунта?</summary>

Мод меняет только файлы приложения на вашем компьютере, перед этим сохраняя резервную копию.
Он не трогает логин, пароль и подписку и никуда не отправляет данные. Код открыт целиком.
</details>

<details>
<summary>Статус в Discord не появляется</summary>

В Discord: Настройки → Конфиденциальность активности → включите «Делиться активностью».
Discord должен быть запущен на этом же компьютере.
</details>

<details>
<summary>Мод пропал</summary>

Запустите установщик ещё раз. Если опция автовосстановления выключена, после каждого обновления
Яндекс Музыки это нужно делать вручную.
</details>

<details>
<summary>Что-то сломалось</summary>

Нажмите «Удалить» в установщике, приложение вернётся к исходному виду. Создайте
[issue](https://github.com/attent10nc/YMusicMod/issues) и укажите версию Яндекс Музыки.
</details>

## Сборка

Понадобятся Windows и Node.js 18+. Компилятор C# входит в .NET Framework, который уже есть в системе.

```powershell
npm install
npm run build     # dist\YMusicMod-Setup.exe
npm run check     # проверить, встаёт ли мод на установленную версию
npm run patch     # накатить исходники напрямую (Яндекс Музыка должна быть закрыта)
```

```
src/mod/          код, который встраивается в приложение
src/installer/    установщик и фоновый процесс (C#, WinForms)
scripts/          сборка
assets/           логотип и скриншоты
```

Новая версия: поднимите `version` в `package.json`, поставьте тег `vX.Y.Z` и отправьте его в репозиторий.
GitHub Actions соберёт установщик и прикрепит его к релизу.
